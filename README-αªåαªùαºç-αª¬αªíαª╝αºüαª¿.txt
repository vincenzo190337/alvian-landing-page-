ALVINA — সম্পূর্ণ সাইট (Vercel-এর জন্য)

ফাইলগুলো:
  index.html, style.css, script.js, config.js  -> সাইটের মূল ফাইল
  logo.png, hero.png                           -> লোগো ও হিরোর ছবি (স্বচ্ছ ব্যাকগ্রাউন্ড)
  og.jpg                                       -> লিংক শেয়ার করলে যে ছবি দেখায়
  api/order.js                                 -> Telegram-এ অর্ডার পাঠানোর ফাংশন (টোকেন এতে নেই)

GitHub-এ আপলোড (Add file -> Upload files):
  শুধু বদলানো ফাইল দিলেই হবে: index.html, style.css, script.js, config.js  -> Commit changes
  (লোগো/ছবি আগে দেওয়া থাকলে আবার দিতে হবে না; api/order.js-ও না)

এই আপডেটে: হিরোর ব্যাকগ্রাউন্ডের ছবি/গ্রেডিয়েন্ট/রঙিন ঝাপসা দাগ সরিয়ে শুধু সাধারণ হালকা বেগুনি রং রাখা হয়েছে।
ব্যাকগ্রাউন্ডের রং বদলাতে config.js-এর heroBackground-এ রং লিখুন (যেমন "#fbeaf4")। ফাঁকা থাকলে পেজের হালকা বেগুনি।
